# ادبیات‌کده

نمونهٔ آموزشی فارسی برای یادگیری عربی؛ شامل درس‌های صرف، مینی‌دورهٔ نحو، آزمون‌های چندقالبی، مرور زمان‌بندی‌شده، آمار یادگیری و قابلیت نصب و استفادهٔ آفلاین.

## اجرای محلی

برای اجرای PWA و Service Worker، صفحه را از `localhost` یا یک میزبان HTTPS باز کن (بازکردن مستقیم فایل با `file://` حالت آفلاین را فعال نمی‌کند):

```sh
python3 -m http.server 8000
```

سپس به `http://localhost:8000` برو. امکانات پایه و ذخیرهٔ پیشرفت مهمان در همان مرورگر کار می‌کنند.

## فعال‌کردن حساب و همگام‌سازی ابری

1. یک پروژه در Supabase بساز.
2. محتوای `supabase-setup.sql` را در SQL Editor همان پروژه اجرا کن. اگر پروژه را قبلاً راه‌اندازی کرده‌ای، نسخهٔ جدید را دوباره اجرا کن تا ستون‌ها، دسترسی‌ها و ثبت‌نام دوره‌ها به‌روز شوند.
3. نشانی پروژه و کلید **anon/publishable** را در `supabase-config.js` وارد کن. هرگز `service_role` یا کلید محرمانه را در این فایل قرار نده.
4. از صفحهٔ «حساب» با ایمیل و گذرواژهٔ مدیر یک حساب بساز و ایمیل آن را تأیید کن. گذرواژهٔ مدیر را داخل فایل‌های برنامه قرار نده؛ ورود مدیر با همان حساب امن Supabase انجام می‌شود.
5. در SQL Editor نقش مدیر را فقط برای حساب مورداعتماد تنظیم کن (ایمیل را جایگزین کن):

   ```sql
   update public.profiles
   set role = 'admin'
   where id = (select id from auth.users where email = 'admin@example.com');
   ```

ورود، همگام‌سازی پیشرفت، محتوای دوره‌ها، آپلود صدا و بررسی شناسهٔ گواهی پس از این مراحل فعال می‌شوند. پنل «مدیریت» امکان مشاهده و ویرایش کاربران و نقش‌ها، دیدن آمار و ثبت‌نام‌ها، انتشار یا پیش‌نویس‌کردن دوره و درس، باز و بسته‌کردن ثبت‌نام، و افزودن/ویرایش/حذف محتوا را می‌دهد. ثبت‌نام به حساب کاربری نیاز دارد و فقط برای دورهٔ منتشرشده‌ای که ثبت‌نامش باز است انجام می‌شود. محتوای درس به‌صورت JSON ذخیره می‌شود و فایل صوتی تا ۱۰ مگابایت پشتیبانی می‌شود. نمونهٔ محتوای یک درس:

```json
{
  "text": "«البيتُ كبيرٌ» یعنی خانه بزرگ است.",
  "questions": [
    {
      "prompt": "«البيتُ» چه نقشی دارد؟",
      "options": ["مبتدا", "خبر", "فعل"],
      "answer": 0
    }
  ]
}
```

## نکته دربارهٔ گواهی

شناسهٔ آنلاین از طریق Supabase قابل بررسی است، اما این نمونه گواهی آموزشی/دانشگاهی رسمی صادر نمی‌کند. نتیجهٔ آزمون و پیشرفت در سمت کاربر ثبت می‌شود؛ برای گواهی رسمی یا ارزیابی ضدتقلب، باید نمره‌دهی و صدور گواهی به منطق سمت سرور و سیاست‌های سازمان صادرکننده منتقل شود.
